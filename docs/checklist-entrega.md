# Checklist de entrega

## Antes de gravar

- [ ] Clonar os dois repositórios lado a lado.
- [ ] Executar `docker compose up --build` na raiz do front-end.
- [ ] Confirmar interface em `http://localhost:3000`.
- [ ] Confirmar Swagger em `http://localhost:8000/docs`.
- [ ] Sincronizar a Fake Store e confirmar os produtos.
- [ ] Testar cadastro, edição e exclusão pelo painel.
- [ ] Reiniciar os contêineres e confirmar a persistência.
- [ ] Deixar um produto temporário preparado para demonstrar o DELETE.

## Repositórios

- [ ] Repositório do front-end público.
- [ ] Repositório da API público.
- [ ] Dockerfile na raiz dos dois repositórios.
- [ ] `docker-compose.yml` na raiz do front-end.
- [ ] READMEs revisados.
- [ ] Fluxograma visível no README principal.

## Vídeo

- [ ] Duração máxima de 6 minutos.
- [ ] Objetivo e problema apresentados.
- [ ] Arquitetura apresentada.
- [ ] API externa apresentada.
- [ ] Todas as rotas demonstradas no Swagger.
- [ ] Interface executada via Docker.
- [ ] Chamadas aos componentes demonstradas.

## Mensagem de entrega

Usar URLs completas, iniciadas por `https://`, para o vídeo, os dois repositórios e a Fake Store API.
